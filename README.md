# DIIAUS Skills

Reusable AI agent skills for Codex, organized by engineering domain.

## Catalog

- [`skills/engineering/senior-codecraft`](skills/engineering/senior-codecraft/SKILL.md): pragmatic, concise, maintainable NestJS, TypeScript, and Python engineering standards.
- `skills/devops`: infrastructure and operations skills (planned).
- `skills/data-engineering`: data pipeline and analytical system skills (planned).
- `skills/productivity`: agent workflows and handoffs (planned).

## Install

Use `scripts/install.ps1` on Windows to install `senior-codecraft` to the current user's Codex skills directory. Review scripts before execution.

## Principles

Prioritize correctness, readability, type safety, low coupling, small diffs, and evidence-based verification. Never commit credentials or secrets.
