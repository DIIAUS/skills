# Global Coding Guidance

Apply these principles when working with the skills in this repository:
- Favor correct, readable, concise, idiomatic implementations.
- Prefer feature-first pragmatic modular architecture.
- Follow existing project conventions before restructuring.
- Use strict typing and explicit validation at trust boundaries.
- Avoid needless abstractions, wrappers, interfaces, and boilerplate.
- Make small scoped changes; preserve existing behavior and API contracts.
- Benchmark performance changes and verify with available checks.
- Do not expose secrets or embed credentials.
- Read skills/engineering/senior-codecraft/SKILL.md for the detailed workflow.
